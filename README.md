# orangegames-pack

Unified resource pack for the Orange Games server. Replaces ItemsAdder's self-hosted
pack (and vendors BetterHud's generated assets) with a single GitHub-hosted zip.

## Contents

- `assets/orangegames` — custom items, equipment, sounds (from Orange Games Resourcepack)
- `assets/orangecosmetics` — cosmetic hats (from Orange Games Cosmetics)
- `assets/betterhud` + `assets/minecraft` — HUD fonts/textures and transparent
  boss bar sprites (generated by BetterHud 2.0.0 from the server's layout config)
- `betterhud_*` — per-client-version overlay directories containing the patched
  text shaders that reposition HUD elements:

| Overlay | Pack formats | Client versions |
|---|---|---|
| `betterhud_1_21_2` | 9–45 | up to 1.21.3 |
| `betterhud_1_21_4` | 46–55 | 1.21.4–1.21.5 |
| `betterhud_1_21_6` | 56–83 | 1.21.6–1.21.11 |
| `betterhud_26_1` | 84–87 | 26.1.x |
| `betterhud_26_2` | 88–999 | 26.2+ |

`betterhud_26_2` is hand-ported (26.2 consolidated `rendertype_text*` into
`core/text` with `IS_GUI`/`IS_SEE_THROUGH` defines); the others are BetterHud's
own generated output. If the BetterHud layout config changes, regenerate and
re-vendor the assets AND update the switch table in
`betterhud_26_2/assets/minecraft/shaders/core/text.vsh` to match the regenerated
26_1 shader.

## Building / deploying

```
python build.py
```

writes `OrangeGamesPack.zip` (deterministic, stable SHA-1) and prints the SHA-1.
Commit the zip, push, then update `resource-pack-sha1` in `server.properties`.
